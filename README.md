# PulseTrack

เครื่องวัดอัตราการเต้นของหัวใจ (BPM) ด้วย Arduino ที่แสดงผลบนจอ LCD 16×2 ผ่าน **ไดรเวอร์ I2C แบบซอฟต์แวร์ที่เขียนขึ้นเอง** และใช้ไฟ LED สีเขียวและสีแดงบอกสถานะ

**website:** [https://YOUR-USERNAME.github.io/YOUR-REPO/](https://68070020-chatrapee.github.io/pulsetrack.github.io/)

## การทำงาน

- อ่านสัญญาณจากเซนเซอร์ชีพจรที่ขา `A2` อย่างต่อเนื่อง
- นับเป็นหนึ่งจังหวะเมื่อสัญญาณสูงกว่า `514` แล้วตกลงต่ำกว่า `512` ระยะเวลาระหว่างจังหวะใช้คำนวณ BPM
- จอ LCD (บอร์ด I2C แบบ PCF8574) ใช้ขา `A0` (SDA) และ `A1` (SCL) โดยไม่ใช้ `Wire.h` ฟังก์ชัน `i2cStart()`, `i2cWriteByte()` และ `i2cStop()` สลับสถานะขาโดยตรง
- จอจะอัปเดตเฉพาะเมื่อค่า BPM เปลี่ยน และไม่เกินทุก 250 มิลลิวินาที เพื่อไม่ให้การเขียน I2C ที่ช้ารบกวนการอ่านค่าชีพจร

## อุปกรณ์และการต่อวงจร

| ชิ้นส่วน | ขาของชิ้นส่วน | ขา Arduino |
| :-- | :-- | :-- |
| เซนเซอร์ชีพจร | สัญญาณ (S) | `A2` |
| จอ LCD 16×2 (บอร์ด I2C) | SDA | `A0` |
| จอ LCD 16×2 (บอร์ด I2C) | SCL | `A1` |
| ไฟ LED สีเขียว | ขาบวก (+) | `D6` |
| ไฟ LED สีแดง | ขาบวก (+) | `D7` |
| ทุกชิ้นส่วน | VCC / GND | 5V / GND |

ต่อตัวต้านทาน 220 Ω ถึง 1 kΩ อนุกรมกับ LED แต่ละดวง

## ระดับ BPM

| BPM | ข้อความบนจอ | ไฟเขียว | ไฟแดง |
| :-- | :-- | :-- | :-- |
| ≤ 40 | Reading... | ดับ | ดับ |
| 41–59 | Low | ดับ | ติด |
| 60–100 | Normal | ติด | ดับ |
| > 100 | High | ดับ | ติด |

## เริ่มต้นใช้งาน

1. ต่อวงจรตามตารางด้านบน
2. เปิด `pulse_monitor.ino` ด้วย Arduino IDE แล้วอัปโหลดลงบอร์ด
3. วางนิ้วบนเซนเซอร์ และรอสักครู่ให้ตรวจจับได้หลายจังหวะ

**แก้ปัญหาเบื้องต้น**

- จอไม่แสดงผล: เปลี่ยน `LCD_ADDR` จาก `0x27` เป็น `0x3F` และลองปรับตัวต้านทานปรับค่าความคมชัดบนบอร์ด I2C
- ค่า BPM ผิดหรือแกว่ง: เปิด Serial Plotter (9600 baud) แล้วปรับ `UpperThreshold` และ `LowerThreshold` ให้อยู่รอบค่ากึ่งกลางของสัญญาณ
